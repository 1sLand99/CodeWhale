## Approval rails (hard)

No agent takes these without explicit, per-action approval from Hunter:

- push to protected `origin/main`; force-push or rewrite of any shared ref
- tag creation or move, GitHub Release
- crates.io / npm publication, artifact upload, Homebrew tap update
- any deployment (Codewhale web, `app.codewhale.net`, CWC #123)
- production credentials, billing/Stripe, DNS, customer-data mutation
- paid/live-provider entitlement tests (e.g. Kimi Code K3), signing/notarization
- approving `action_required` fork workflow runs — running an outside
  contributor's code on org runners is a trust decision, not a CI chore
- contributor-facing communication that closes or rejects community work

Standing engineering rails: land through small reviewable commits or PRs;
preserve contributor authorship and `Co-authored-by` / `Harvested from PR #N`
credit; never close an issue without per-criterion receipts on the landed SHA;
never run probes or tests against the real `~/.codewhale` — seal `HOME` and
`CODEWHALE_HOME`.

Two standing facts about these gates, both load-bearing:

- The clippy step runs **without `--all-targets`**, so `cfg(test)` and
  integration-test code is never linted. A bare `--all-targets -D warnings` run
  surfaces pre-existing errors in test code. Those are not regressions; do not
  "fix" them, and do not treat a locally-remembered clippy command as CI's.
- The current `link` (PR↔issue) gate fetches the live PR body. Older campaign
  notes describing stale event-payload behavior are historical and must not be
  used to diagnose a current failure.

## Working model: direct local `main`, no PR

Release-lane work in this worktree lands as **small, reviewable commits on the
local branch**, not as GitHub PRs. Consequences to hold onto:

- No `link` check and no PR review gate runs, so the discipline they enforce is
  yours: one concern per commit with a real body, and no closing keyword unless
  the acceptance criteria are actually met on the landed tree.
- CI gates still apply and must be run locally with the exact commands above
  before anything is proposed for `main`; local green is the evidence, but it is
  not hosted-green and must not be described as such.
- Pushing this branch to protected `main` remains Hunter-gated. The branch is a
  candidate, not a landing.
- Contributor work never enters this way. Anything with an outside author goes
  through the harvest path with `Co-authored-by` / `Harvested from PR #N` intact
  and a merge or rebase (never a squash, which rewrites the credit line).
